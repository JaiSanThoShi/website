# Jai Santhoshi's website

## How to edit

1. Go to **https://app.pagescms.org** and sign in with GitHub.
2. Open the **website** repository.
3. Pick a section on the left, change or add entries, upload photos, and press **Save**.
4. The live site updates about a minute later.

## What's in the editor

- **✦ Site design**: which pages appear in the side panel (drag to reorder, rename, untick to hide), font, text size, starting accent colour, morning background, page width, fairy lights, typewriter greeting, painted dots, travel photo style and gallery columns.
- **Get to know me**: about, timeline and hobbies; paintings; and reading, listening and watching.
- **My 9–5**, **Travel**, **Podcast**, **Blog** (Substack posts and old posts) and **Projects**.

Tips:
- Wrap words in `==double equals==` for a watercolour brushstroke, or to colour your name in the side panel.
- Leave a photo empty and the site shows a soft colour placeholder.
- Visitors can switch between morning and night, and tap the coloured dot to change the accent.

## Where things live

- `content/` holds everything you write, one file per section.
- `images/` holds uploaded photos.
- `index.html` decides how the site looks.
- `.pages.yml` sets up the editing forms.
